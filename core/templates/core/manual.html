Manual de Usuario - Plataforma de Gestión TIC

Documento Oficial de Inducción al Sistema

1. Introducción al Sistema

El Sistema de Gestión TIC del Hospital Provincial Marga Marga es una plataforma de grado empresarial (Enterprise) desarrollada para centralizar la gobernanza de la tecnología hospitalaria. Su diseño integra principios ITIL para la mesa de ayuda, trazabilidad completa de activos y un motor de auditoría riguroso.

2. Gestión de Mesa de Ayuda (Tickets)

El flujo de resolución de incidentes técnicos se estructura mediante un tablero de control (Kanban) que asigna automáticamente las solicitudes a los Grupos Resolutores correspondientes.

2.1. Flujo de un Requerimiento

Fase Descripción del Proceso
Levantamiento El usuario o técnico registra el incidente, especificando la prioridad y la categoría. El sistema asocia la solicitud directamente al activo físico afectado.
Asignación El ticket es enrutado de manera automática al Grupo Resolutor pertinente (ej. Redes, Sistemas Médicos, Soporte). El equipo visualiza la solicitud en su tablero.
Resolución (SLA) Un técnico toma la responsabilidad y cambia el estado a "En Proceso", iniciando la contabilización del Acuerdo de Nivel de Servicio (SLA). El técnico documenta el diagnóstico y la solución aplicada.

3. Inventario y Trazabilidad Físico/Lógica

El control patrimonial tecnológico requiere de una ubicación exacta de los activos dentro del recinto hospitalario. Para esto, el sistema utiliza dos modelos jerárquicos de ubicación que cruzan la dependencia administrativa con la ubicación física.

3.1. Requerimientos de Parametrización

Para la correcta puesta en marcha, se requiere que la Unidad de Infraestructura valide la siguiente taxonomía estructural:

  • Jerarquía Organizacional: Área → Unidades → Recintos → Puntos de Montaje (PMAs).
  • Jerarquía Física: Instituciones → Edificios → Pisos → Sectores.

3.2. Bitácora Clínica del Activo

Cada equipo tecnológico posee una "Bitácora" inmutable. Cada vez que un ticket asociado al equipo es resuelto, el sistema inyecta automáticamente el diagnóstico y la solución en el historial del activo. Esto permite detectar de forma proactiva hardware defectuoso recurrente o con vida útil expirada.

4. Auditoría de Sistemas (Enterprise Logging)

Como sistema de clase gubernamental, la plataforma registra una huella digital inalterable de cada transacción ejecutada.

  • Registro automático de todas las altas, bajas y modificaciones (Creación/Edición/Eliminación).
  • Monitorización de acceso a módulos con captura de fecha, hora y Dirección IP.
  • Tablero de control en tiempo real para el Oficial de Seguridad de la Información.
